## 📐 Finite Element Analysis (FEA)

- [CalculiX](http://www.calculix.de/) - A 3D structural Finite Element program (similar to ABAQUS).
- [Code_Aster](https://www.code-aster.org/) - Advanced structural mechanics and non-linear analysis solver by EDF.
- [SfePy](https://sfepy.org/) - Simple Finite Elements in Python for solving coupled PDEs.
- [FEniCS](https://fenicsproject.org/) - High-performance automated solution of differential equations.
- [AgentFEM](https://github.com/haoming-luo/agentfem) - Python finite-element workflows on FEniCSx/PETSc, with shared modeling and result tools for researchers and AI agents.
- [FreeCAD FEM](https://wiki.freecad.org/FEM_Workbench) - Integrated FEA workbench using CalculiX and Gmsh.

---

## 🌊 Computational Fluid Dynamics (CFD)

- [OpenFOAM](https://www.openfoam.com/) - The leading free, open-source CFD software for aerodynamics, combustion, and multiphase flows.
- [SU2](https://su2code.github.io/) - Open-source suite for multiphysics simulation and aerodynamic shape optimization.
- [PyFR](http://www.pyfr.org/) - High-order CFD solver for Navier-Stokes on GPUs and clusters.
- [DualSPHysics](https://dual.sphysics.org/) - Smoothed Particle Hydrodynamics (SPH) solver for free-surface fluid flows.

## 🛠️ Computer-Aided Design & CAD Kernels

- [OpenCASCADE (OCCT)](https://dev.opencascade.org/) - Complete C++ 3D surface and solid modeling CAD kernel (B-Rep, STEP, IGES).
- [FreeCAD](https://www.freecad.org/) - Parametric 3D modeler with BIM, CAM, FEM, and Robot simulation workbenches.
- [OpenSCAD](https://openscad.org/) - The programmers' solid 3D CAD modeler (CSG geometry via code).
- [CadQuery](https://cadquery.readthedocs.io/) - Python parametric CAD scripting framework based on OpenCASCADE.

---

## 🤖 Robotics & Multi-Body Dynamics (MBD)

- [ROS / ROS 2](https://www.ros.org/) - Robot Operating System framework and ecosystem.
- [Chrono::Engine](https://projectchrono.org/) - Multi-body physics simulation engine for vehicles, robotics, and granular dynamics.
- [Drake](https://drake.mit.edu/) - Model-based design and verification for robotics by MIT CSAIL.
- [PyBullet](https://pybullet.org/) - Fast physics simulation for robotics, reinforcement learning, and VR.

---

## 🔋 Electric Vehicles & Battery Systems

- [PyBaMM](https://pybamm.org/) - Python Battery Mathematical Modeling (DFN, SPM, lumped thermal battery models).
- [FASTSim](https://www.nrel.gov/transportation/fastsim.html) - Powertrain efficiency and fuel economy simulator by NREL.

---

## 🐍 Python Engineering Libraries

- [NumPy](https://numpy.org/) & [SciPy](https://scipy.org/) - Fundamental matrix operations, differential equation solvers, and linear algebra.
- [SymPy](https://www.sympy.org/) - Symbolic mathematics for kinematics and dynamics equations.
- [Cantera](https://cantera.org/) - Chemical kinetics, thermodynamics, and transport processes.
- [CoolProp](http://www.coolprop.org/) - Open-source thermodynamic properties database (steam tables, refrigerants).
